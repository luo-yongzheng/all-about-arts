## 真实阻塞与发布边界

1. **Codex 独立宿主验收未通过。** 宿主找到了 Skill 并制作了工程，但该独立 CLI 会话的 `workspace-write` 沙盒阻止 macOS 启动 Chrome。宿主产生了降级媒体并诚实报告真实 CLI 渲染受阻；降级输出没有计作通过。
2. **Claude Code 独立宿主验收未运行成功。** 已配置宿主返回 OAuth 会话过期，并报告配置模型不可用。没有更改用户的登录、模型或权限设置。
3. **八种风格尚未获得完整创作认证。** 两个题材配置、专属对象动作、横竖屏和渲染测试证明了当前示例的实现路径。接触表记录实际题材动作，两支口播按镜头放置声音，词时间标为句内插值。仍需由两个宿主完成独立 brief 与修改任务，补齐逐镜头的叙事和声画评审；不能从示例推断任意新题材都能自动迁移。
4. **当前是选择性整合。** 厚涂保留专门引擎，玻璃采用物理材质；纸雕采用 Canvas 光箱改写。配乐是确定性程序合成子集，尚未移入 Lemo 的完整采样乐器库。图片生成由宿主工具和来源回执接入，项目不内置某一云厂商账号或自动下载模型。
5. **平台实测范围是本机 macOS。** Linux 核心兼容代码没有在本次真实 Linux 环境跑过；Windows 不承诺支持。字体/GPU 差异不承诺跨机器像素一致。

v1 发布前需在可用的两种宿主环境完成独立行为矩阵，并补齐八种风格的创作与修改验收。目录保留 `integrated` 状态与 0.1.0 版本正是为了避免把工程可运行混同于所有发布条件已满足。
