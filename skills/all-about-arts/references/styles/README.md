# Style references

The 51 STYLE.md documents are copied verbatim from Lemo-Opuscar commit 508848acb2b4930c4041fef4d594120da1525bff under MIT. Relative demo/script links inside these historical documents describe the original library and may not exist in this package. They are references, not setup instructions or required files. Use this package's runtime and CLI for production; never clone an original repository merely to resolve such a link. The documents describe artistic grammar, not finished films for a new brief.

The [catalog](../../styles/catalog.json) records eight reusable engine adaptations and their limitations. Their wrappers and examples are starting compositions: several two-topic examples reuse a subject or layout while changing the text and items. They do not establish universal content transfer or fully certified storytelling. Each new story still needs creative acceptance. No style is automatically certified.

Maintain the catalog, local engines and examples directly. New styles can be developed from the bundled references and tested with the same runtime contract; there is no upstream catalog generator or update dependency.
