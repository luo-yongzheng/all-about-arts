# Style references

All 99 styles can be recommended and used for native authoring through `lemo init <project> --style <slug>`. The catalog's top-level `reference` / `integrated` status describes legacy preset availability only. Do not filter recommendations to the eight integrated presets or wait for visual certification. `styles --json` returns all entries with status definitions; it also searches English/Chinese names, categories and English use cases. For topic recommendations, consult the full catalog if a keyword has no match.

The 99 STYLE.md documents match the bundled Lemo-Opuscar 2.0.x snapshot at commit 00a7f9ec99c8686265a8ca4ed9a3fdaaf27ea6f4. Like their originals they are CC BY-NC 4.0 docs with Lemomo's permission to use them for your own films; see [THIRD_PARTY.md](../../THIRD_PARTY.md). For production read the canonical files in [vendor/lemo-opuscar/styles](../../vendor/lemo-opuscar/styles/README.md): their relative links resolve to the complete demo source, guides and assets. These copies support existing references. The style grammar is not a finished film for a new brief.

The [catalog](../../styles/catalog.json) records eight reusable engine adaptations and their limitations. Their wrappers and examples are starting compositions: several two-topic examples reuse a subject or layout while changing the text and items. They do not establish universal content transfer or fully certified storytelling. Each new story still needs creative acceptance. No style is automatically certified.

Every catalog entry now has a `native` route, including actual demo entry, guide, poster and credits. `native.engine` is `web` or `python`; `requires` lists extra capabilities such as `image-generation`. `source-available` means the source is included, not that external assets are installed or artistic quality is certified. Use [native production](../native-lemo.md) for original work. The [snapshot manifest](../../provenance/lemo-snapshot.json) verifies every imported file; migration from an explicitly supplied local checkout does not fetch or track latest automatically.
